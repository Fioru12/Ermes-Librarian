# Ermes Knowledge web application

React and Vite frontend for the Ermes Knowledge document-library workflow.

```bash
npm install
npm run dev
```

The development server runs on port `3000` and proxies API requests to the FastAPI backend on port `8502`.

Useful commands:

```bash
npm test
npm run build
npm run lint
```

The UI must keep the selected library visible while asking questions and render citations as inspectable document evidence.
