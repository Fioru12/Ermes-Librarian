# Archivio Legacy

Questa cartella raccoglie riferimenti storici e file obsoleti del progetto.

Indicazioni operative attuali:
- Avvio principale: `AVVIA_PRO.bat`
- Avvio alternativo per sviluppo: `launch.py`
- Avvio backend diretto: `uvicorn api:app --host 127.0.0.1 --port 8504`

Note:
- i file vecchi non vanno usati come punti di avvio ufficiali
- WinSarp resta il modulo specializzato principale
- i futuri moduli aziendali possono essere aggiunti senza toccare WinSarp
